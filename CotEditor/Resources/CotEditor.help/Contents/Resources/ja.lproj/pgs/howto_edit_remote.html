MacのCotEditorでリモートファイルを編集する

rmateプロトコルを使うと、リモートコンピュータ上のテキストファイルをMacのCotEditorで開けます。書類を保存すると、同じ接続を通じて変更内容がリモートファイルに送信されます。

リモート編集を設定する

  1. リモートコンピュータにrmateクライアントをインストールします。例えば、TextMateのrmateクライアントを使用できます。リモートコンピュータの環境に合わせて、クライアントのインストール手順に従ってください。

  2. MacのCotEditorで「CotEditor」＞「設定」と選択してから、「一般」をクリックします。

  3. 「リモート編集」セクションの「rmate接続を許可」を選択し、ポート番号を確認します。デフォルトは52698です。

CotEditorはMac自身からの接続のみを受け入れます。以下の手順のようにSSHのポート転送を使って、リモートクライアントからCotEditorに接続します。リモート側のSSHサーバでポート転送が許可されている必要があります。

リモートファイルを開く

  1. MacでCotEditorを起動しておきます。

  2. Macのターミナルで、SSHトンネルを作成してリモートコンピュータに接続します:

    ssh -o ExitOnForwardFailure=yes -R 52698:127.0.0.1:52698 user@example.com

    user@example.comを自分のユーザ名とリモートコンピュータのアドレスに置き換えてください。リモート側のポート52698がMacのCotEditorに転送されます。

  3. そのSSHセッションで、編集するファイルのパスを指定してrmateを実行します:

    rmate --host 127.0.0.1 --port 52698 path/to/file.txt

    CotEditorでファイルが開き、ウインドウのサブタイトルに「リモート」と表示されます。

別のポートを使う場合は、SSHコマンド内の2箇所の52698と、rmateコマンドのポート番号をその番号に置き換えます。CotEditorの「一般」設定にも同じ番号を指定してください。

書類を閉じるまでrmateの終了を待たせるには、--waitオプションを追加します。編集を終えてリモート書類を閉じるまで、SSHセッションを開いたままにしてください。

シンタックスを指定して開くには、--typeに続けてCotEditorのシンタックス名を指定します。ユーザ定義のシンタックスも指定できます。大文字と小文字を含めて名前を正確に指定し、空白を含む名前は引用符で囲んでください:

rmate --host 127.0.0.1 --port 52698 --type Python /path/to/script

--typeを省略した場合や、一致するシンタックス名がない場合は、通常どおりシンタックスを自動判定します。

変更内容を保存する

「ファイル」＞「保存」を選択するか、Command+Sを押すと、変更内容がリモートファイルに送信されます。「一般」設定で「オートセーブとバージョンを有効にする」が選択されている場合は、自動保存でも変更内容がリモートファイルに送信されます。

書類をMacに保存するには、「ファイル」＞「別名で保存」を選択します。Macに保存するとリモートファイルとの関連が解除され、それ以降はMac上のファイルだけが更新されます。

CotEditorを終了すると、接続中のリモート書類は閉じられ、次回起動時には復元されません。再びリモート編集するには、rmateを実行して開き直してください。

接続が切断された場合

SSHセッションやrmateクライアントの接続が切断されると、ウインドウのサブタイトルが「切断済み」に変わります。編集を続けることはできますが、変更内容をリモートファイルに送信できなくなります。

未送信の変更内容がある場合は、Macへの保存を促すダイアログが表示されます。「別名で保存」をクリックし、Mac上の保存先を選択して変更内容を残してください。ファイル名を変える必要はありません。「あとで」をクリックすると書類は開いたままになりますが、接続は復旧しません。

CotEditorは開いている書類を自動的に再接続しません。リモート編集を再開するには、変更内容をMacに保存してからSSHトンネルを作成し直し、rmateを再度実行します。新たに開いたリモート書類に必要な変更内容をコピーして保存してください。

切断後に未送信の変更内容を保持している書類は、「一般」設定で「最後のセッションのウインドウを開く」が選択されている場合、引き続き復元の対象になります。また、予期せず終了した場合は、復旧用コピーからリモート書類を復元できます。復元した書類の接続は切れたままです。内容をMacに残すには「別名で保存」を使用してください。

ファイルが開かない場合

  • CotEditorが起動していて、「一般」設定の「rmate接続を許可」が選択されていることを確認してください。

  • SSHトンネルが作成され、ポート番号が一致していることを確認してください。ポートがすでに使われている場合は、ほかの受信アプリを停止するか、別のポートを選んでください。

  • リモート側のターミナルで、SSHやrmateからエラーが出ていないか確認してください。ファイルが存在しない場合やアクセス権がない場合などにエラーが表示されます。

  • リモート編集で開けるファイルの大きさは100 MBまでです。
