Edit remote files in CotEditor on Mac

With the rmate protocol, you can open a text file on a remote computer in CotEditor on your Mac. When you save the document, CotEditor sends the changes back to the remote file through the same connection.

Set up remote editing

rmate is an external command-line tool for opening files on a remote computer in an editor on your Mac. It is not included with macOS or CotEditor, so you need to install and run it on the remote computer.

  1. Install an rmate client on the remote computer. For example, you can use TextMate’s rmate client. Follow the client’s installation instructions for your remote computer.

  2. In CotEditor on your Mac, choose CotEditor > Settings, then click Integration.

  3. Select “Accept rmate connections” in the Remote Editing section and check the port number. The default is 52698.

CotEditor accepts connections only from your Mac. Use SSH port forwarding to connect the remote client to CotEditor, as shown below. The remote SSH server must allow port forwarding.

Open a remote file

  1. Keep CotEditor running on your Mac.

  2. In Terminal on your Mac, connect to the remote computer with an SSH tunnel:

    ssh -o ExitOnForwardFailure=yes -R 52698:127.0.0.1:52698 user@example.com

    Replace user@example.com with your user name and the remote computer’s address. This forwards the remote computer’s port 52698 to CotEditor on your Mac.

  3. In that SSH session, run rmate with the path of the file you want to edit:

    rmate --host 127.0.0.1 --port 52698 path/to/file.txt

    The file opens in CotEditor with “Remote” in the window’s subtitle.

If you use a different port, replace both occurrences of 52698 in the SSH command and the port in the rmate command with that number. Use the same number in CotEditor’s Integration settings.

To keep rmate waiting until you close the document, add the --wait option. Keep the SSH session open until you finish editing and close the remote documents.

To choose a syntax when opening the file, add --type followed by a CotEditor syntax name. You can also specify a custom syntax. Use the exact name, including capitalization, and enclose names containing spaces in quotes:

rmate --host 127.0.0.1 --port 52698 --type Python /path/to/script

If --type is omitted or does not match a syntax name, CotEditor detects the syntax as usual.

Save your changes

Choose File > Save or press Command-S to send your changes to the remote file. If “Enable Auto Save with Versions” is selected in General settings, automatic saves also send changes to the remote file.

To keep the document on your Mac instead, choose File > Save As. After you save it on your Mac, the document is no longer associated with the remote file, and subsequent saves update only the local file.

When you quit CotEditor, connected remote documents close and do not reopen at the next launch. Run rmate again to open them for remote editing.

If the connection is lost

If the SSH session or the rmate client disconnects, the window’s subtitle changes to “Disconnected.” You can continue editing, but CotEditor can no longer send changes to the remote file.

When there are unsent changes, CotEditor shows a dialog offering to save the document on your Mac. Click Save As and choose a local location to keep your changes. The filename can stay the same. Clicking Later keeps the document open, but does not restore the connection.

CotEditor does not automatically reconnect an open document. To resume remote editing, save your changes on your Mac, establish the SSH tunnel again, and run rmate again. Copy any changes you want to keep into the newly opened remote document, then save it.

Disconnected documents with unsent changes remain eligible for restoration when “Reopen windows from last session” is selected in General settings. After an unexpected quit, CotEditor can also restore remote documents from recovery copies. Restored documents remain disconnected; use Save As to keep their contents on your Mac.

If a file doesn’t open

  • Check that CotEditor is running and “Accept rmate connections” is selected in Integration settings.

  • Check that the SSH tunnel was established and that the port numbers match. If the port is already in use, stop the other receiver or choose another port.

  • Check the remote terminal for errors from SSH or rmate, such as a missing file or insufficient permissions.

  • Remote editing supports files up to 100 MB.
