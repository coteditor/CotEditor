Change Shortcuts settings in CotEditor on Mac

In the CotEditor app on your Mac, use Shortcuts settings to change keyboard shortcuts for menu commands and text editing commands.

To change these settings, choose CotEditor > Settings, then click Shortcuts.

OptionDescription
Menu

Change keyboard shortcuts for menu commands. To change a shortcut, click the key column for the command, then press the new key combination. To remove the shortcut, press Delete instead of a key combination.

If the shortcut is already in use or otherwise unavailable, CotEditor keeps the current setting and shows an error. For details, see Customize keyboard shortcuts.
Text Editing

Change keyboard shortcuts for commands that move the insertion point or select, delete, or scroll text in the editor. A command can have more than one shortcut.

To edit the shortcuts for a command, do any of the following:

  • Add a shortcut: Click the empty space on the left side of the key column for the command, then press the new key combination.

  • Change a shortcut: Click the shortcut, then press the new key combination.

  • Remove a shortcut: Click the shortcut, then press Delete.

If you remove all shortcuts for a command, its default shortcuts appear dimmed and don’t work.

In addition to the key combinations available for menu commands, you can assign the arrow keys and the Forward Delete key without modifier keys. If you assign a shortcut that another text editing command uses by default, the shortcut moves to the command you’re changing.
Restore Defaults

Restore all customized keyboard shortcuts for both menu commands and text editing commands to their default settings. To restore the default shortcuts for a single command, open the contextual menu for the command, then choose Restore Defaults.
